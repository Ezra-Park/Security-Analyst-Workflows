# 05 - GRC & Policy Examples

## Purpose

This section of the Security Analyst Workflows portfolio contains sample Governance, Risk, and Compliance (GRC) documents that I have developed. These artifacts demonstrate foundational knowledge in security policy development, risk management principles, procedural documentation, and security awareness initiatives.

The goal is to showcase the ability to translate cybersecurity best practices and framework requirements (such as those found in NIST or ISO standards) into clear, actionable guidance suitable for organizational use.


## Context

Please note: These documents are anonymized samples, often derived from volunteer consulting engagements or personal projects, intended to demonstrate capabilities in GRC documentation. Specific details (e.g., contact points, tool names) have been generalized.
